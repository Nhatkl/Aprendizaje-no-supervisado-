# Agrupamiento de dígitos con K‑Means

[![Open In Colab](https://colab.research.google.com/drive/1QYfz7yzpf3iZs_PiSuSW1i0ADQ7Coz07?usp=sharing)](https://colab.research.google.com/github/Nhatkl/Aprendizaje_no_supervisado (1)/blob/main/Aprendizaje_no_supervisado (1).ipynb)

## Descripción
En este proyecto aplico el algoritmo de clustering **K‑Means** al dataset **digits** de scikit‑learn.  
Se exploran valores de K = 10, 8, 6 y 4, mostrando gráficamente las imágenes de cada grupo y comparando los resultados con las etiquetas reales mediante tablas de contingencia.

## Contenido
- Carga y preprocesamiento (inversión de colores).
- Visualización de una muestra.
- Entrenamiento del modelo con diferentes K.
- Análisis de resultados (tablas y gráficas).

## Cómo ejecutar
1. Descarga el archivo `.ipynb`.
2. Ábrelo en [Google Colab](https://colab.research.google.com) o en Jupyter.
3. Ejecuta todas las celdas en orden.

- Python 3
